Example

The following pseudo-code example shows how to run the use-case library. Please refer to the full embedded example how to receive radar frames on an embedded platform.

/* Init use-case algorithm */
ifx_usecase_handle usecase_handle = ifx_usecase_init(NULL);

for(;;)
{
    /* wait for new radar frame */
    const uint16_t* radar_frame_data = ...;

    /* run usecase with radar frame */
    ifx_event_flags events_flags = IFX_EVENT_FLAG_NONE;

    bool reset = false;
    ifx_usecase_process(usecase_handle, reset, radar_frame_data, &events_flags);

    /* check for presence events */
    const ifx_presence_event* presence_event = NULL;
    if(event_flags & IFX_EVENT_FLAG_PRESENCE)
    {
        if(ifx_usecase_get_presence_event(handle, &presence_event) >= 0)
        {
            /* handle presence event */
        }
    }


    /* check for tracking events */
    const ifx_tracking_event* tracking_events = NULL;
    uint32_t tracking_event_count = 0;
    if(event_flags & IFX_EVENT_FLAG_TRACKING)
    {
        if(ifx_usecase_get_tracking_events(handle, &tracking_events, &tracking_event_count) >= 0)
        {
            /* handle tracking events */
        }
    }


    /* check for detection events */
    const ifx_detection* detections = NULL;
    uint32_t detections_count = 0;
    if(event_flags & IFX_EVENT_FLAG_DETECTIONS)
    {
        if(ifx_usecase_get_detections(handle, &detections, &detections_count) >= 0)
        {
            /* handle detection events */
        }
    }
}

/* de-initialize the library */
ifx_usecase_deinit(&usecase_handle);

Initialization

int ifx_usecase_get_version(const char **sem_ver, const char **name, const char **build)

Retrieves the version information of the use case.

This function returns the version information of the use case, including the semantic version, name, and build information.

Parameters:

  • sem_ver – [out] The semantic version of the use case (e.g., “1.2.3”).

  • name – [out] The name of the use case.

  • build – [out] The build information of the use case.

Returns:

0 on success, a negative value on error.

ifx_usecase_handle ifx_usecase_init(const ifx_usecase_configuration *cfg)

Initializes a use case with a given configuration.

This function initializes a use case with the provided configuration. The configuration can be customized using the default configuration as a starting point.

Parameters:

cfg – [in] The configuration for the use case.

Returns:

A handle to the initialized use case

int ifx_usecase_deinit(ifx_usecase_handle *handle)

Deinitializes a use case.

This function releases any resources allocated by the use case and deinitializes it.

Parameters:

handle – [inout] Usecase handle

Returns:

0 on success, a negative value on error.

Configuration

Please see page algorithm how the configuration is processed.

Please note that the configuration is meant as static parameters that cannot be changed while the use-case is running. Use ifx_usecase_init to overwrite the default configuration.

Processing

int ifx_usecase_process(ifx_usecase_handle handle, bool reset, const uint16_t *frame, ifx_event_flags *event_flags)

Process a radar frame and return raised event flags.

Parameters:

  • handle – Usecase handle

  • reset – True if the pipeline needs to be reset

  • frame – Radar frame

  • event_flags – Events raised by the last call. The raised events shall be collected through ifx_usecase_get_presence_event and other collecting functions.

Returns:

0 on success, a negative value on error.

int ifx_usecase_get_presence_event(ifx_usecase_handle handle, const ifx_presence_event **presence_event)

Gets a pointer to the presence event.

See also

ifx_presence_event

Note

Parameters:

  • handle – Usecase handle

  • presence_event – [out] A pointer to a pointer of type ifx_presence_event, which will point to the internal retrieved presence event structure.

Returns:

0 on success, a negative value on error.
