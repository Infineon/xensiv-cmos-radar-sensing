Overview

The pipeline wrapper provides a simple C API for processing radar frames. It abstracts the complex processing pipeline into three main functions: getting default configuration, initializing the pipeline, and processing frames.

Note: The structures ifx_var_config_t and ifx_result_t contain algorithm-specific data and should be accessed and modified through the usecase high-level API.

Example

The following pseudo-code example shows how to use the wrapper API:

/* Get default configuration */
ifx_var_config_t config;
if (pipeline_get_default_config(&config) != 0) {
    /* handle error */
}

/* Initialize the pipeline */
if (pipeline_init(&config) != 0) {
    /* handle error */
}

for (;;) {
    /* Wait for new radar frame */
    const uint16_t* radar_frame = ...; /* 3264 uint16 values */

    /* Process the frame */
    ifx_result_t result;
    if (pipeline_process(radar_frame, &result) != 0) {
        /* handle error */
    }

    /* Use the result */
    /* result contains the processed output */
}

Configuration

int pipeline_get_default_config(ifx_var_config_t *config)

Get default configuration.

Fills the provided config structure with default values

Parameters:

config – Configuration structure to fill

Returns:

0 on success, non-zero on error

Initialization

int pipeline_init(const ifx_var_config_t *config)

Configure and initialize the processing pipeline.

Must be called before any processing

Parameters:

config – Configuration structure

Returns:

0 on success, non-zero on error

Processing

int pipeline_process(const uint16_t *radar_frame, ifx_result_t *output)

Process a radar frame using stateful wrapper API.

Parameters:

  • radar_frame – Input radar frame data (3264 uint16 values)

  • output – Output structure (will be filled by this function)

Returns:

0 on success, non-zero on error
